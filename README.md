# 👑 Guia de Clash Royale

Este projeto é um guia interativo focado no universo de **Clash Royale**, desenvolvido com o objetivo de ajudar jogadores a conhecerem melhor as cartas, estratégias e dicas para subir de arena.

O site foi construído de forma simples e intuitiva, ideal para quem quer consultar informações rápidas sobre o jogo.

---

## ✨ Funcionalidades

- 🛡️ **Guia de Cartas**: Informações e detalhes sobre várias cartas do jogo.
- 💡 **Dicas e Estratégias**: Dicas úteis para melhorar o posicionamento e a gestão de elixir nas partidas.
- 🎨 **Design Intuitivo**: Interface limpa e agradável para uma boa experiência de navegação.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram usadas no desenvolvimento deste projeto:
- **HTML5** (Estrutura das páginas)
- **CSS3** (Estilização e design visual)
